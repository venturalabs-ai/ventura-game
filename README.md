**Experimento de geração assistida de jogos 2D a partir de descrições em linguagem natural.**

> Ecossistema Ventura · [Ventura Studio](https://github.com/venturalabs-ai/ventura-studio)

## Maturidade

**Incubation / experimental.** O repositório ainda representa uma base de exploração técnica, não um gerador de jogos pronto para uso.

## Escopo planejado

- definição de gênero, tema e dificuldade por prompt;
- geração procedural de níveis;
- export para web/desktop;
- exemplos jogáveis e validação automatizada.

## Stack alvo

`Python` · `Pygame` · `FastAPI` · `Docker`

## Critérios para Beta

- protótipo jogável reproduzível;
- testes do core;
- CI bloqueante;
- exemplos versionados;
- documentação de arquitetura;
- primeira release semântica.
