# VenturaGame

**Geração de jogos 2D com IA** a partir de descrições em linguagem natural.

> Ecossistema **Ventura** · [Ventura Studio](https://github.com/chamseddinehiddoud/ventura-studio)

## Funcionalidades

- Geração por prompt (gênero, tema, dificuldade)
- Níveis procedurais
- Export planejado (web / desktop)

## Stack planejada

Python · Pygame · FastAPI · Docker
